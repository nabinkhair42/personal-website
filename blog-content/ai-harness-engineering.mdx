# What is AI Harness?

Harness is the software or the piece of code and is not a model itself.

To convert a raw model into an agent, we need to wrap the model with a harness. The harness provide the complete environment for the model to execute tasks and interact with the outside world for solving complex problems.

Without harness, a model is just a black box that takes input and produces output. With harness, the model can be integrated into a larger system, allowing it to access external resources, manage its own state, and interact with users or other systems.

Harness can include features such as:

- **Orchestration**: Creating sub-agents, managing the flow of information, and coordinating the execution of tasks.
- **System Prompts**: Providing instructions and context to the model to guide its behavior and decision-making.
- **Tools**: Integrating external tools and APIs that the model can use to perform specific tasks or access information.
- **MCP**: Model Context Protocols that allow the model to manage and utilize its context effectively by communicating with the external worlds via certain protocols.
- **Hooks**: Allowing the model to trigger specific actions or events based on certain conditions or outputs.
